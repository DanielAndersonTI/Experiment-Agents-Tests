# Expert Evaluation of LLM-Generated Architectures

This directory contains all the artifacts related to the expert evaluation conducted on LLM-generated software architectures. The evaluation was performed as a blind review.

Below is a breakdown of the contents of each file in this folder.

---

## Folder Contents

### 1. Evaluation Protocol
- **File:** `Expert_Evaluation_Protocol.docx`
- **Description:** This document outlines the complete evaluation protocol. It provides a detailed explanation of what each section of the evaluation form represents, giving context to the overall structure of the assessment.

### 2. Form Details and Scales
- **File:** `Expert_Evaluation_Form.docx`
- **Description:** This file provides supplementary details about the evaluation form. It contains specific information on the scale used for the **Quantitative Assessment** and lists the exact questions that were part of the **Qualitative Feedback** section.

### 3. Blank Evaluation Form
- **File:** `Expert Evaluation of LLM-Generated Architectures (Blind Review) - Formulários Google.pdf`
- **Description:** This is a PDF version of the blank evaluation form that was distributed to the expert reviewers. It represents the exact instrument used to collect the data.

### 4. Collected Responses
- **File:** `Expert Evaluation of LLM-Generated Architectures (Blind Review) (respostas).xlsx`
- **Description:** This spreadsheet contains the complete set of anonymized responses collected from the expert evaluators. Each row typically corresponds to an individual response to the evaluation form.
