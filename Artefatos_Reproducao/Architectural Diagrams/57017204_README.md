# Architectural Diagrams: Bookstore & Petclinic Projects

This directory contains the architectural diagram images for the **Bookstore** and **Petclinic** projects.

The diagrams illustrate a reference architecture for each system. These architectures were generated using Large Language Models (LLMs) with two distinct prompting techniques to explore different levels of detail and context:

1.  **Zero-Shot Prompting:** The architecture was generated from a high-level, direct prompt without any prior examples. This represents a baseline understanding of the system's requirements.
2.  **Few-Shot Prompting:** The architecture was generated by providing the model with a few examples or more detailed contextual information. This approach aims to produce a more refined and specific architectural design.
